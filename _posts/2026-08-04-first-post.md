This file is an example blog post. GitHub Pages supports Jekyll, so you can add new posts by creating Markdown files in the `_posts/YYYY-MM-DD-title.md` format.

## What should I write about?

You can use this space for research notes, project retrospectives, paper summaries, or short reflections on things you have learned while building something.
The blog list on the homepage is generated automatically from files in the `_posts` folder.

## Writing tips

Start with a clear title, date, and short summary. Then divide the body into small sections to make it easier to read.
If you want to include images, place them in the `assets/images` folder and reference them like this:

```markdown
![Image description](/assets/images/example.png)
```
